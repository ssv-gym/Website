    Put it live

    1. If an earlier extract is missing files, delete that folder first.
    2. On GitHub, open the repository → Add file › Upload files → drag in everything inside ssv-gym → Commit changes. Files with the same name are replaced; your favicon and logo stay.
    3. On GitHub, delete js/data.js, apps-script/appsscript.json and assets/placeholders/README.md if they are still there: open the file → trash icon → Commit changes.
    4. Later, for the browser tab icon: upload the SSV logo as assets/favicon.jpg (exactly that name, square, at least 192 × 192 px). Every page already points to it.
    5. Apps Script: paste apps-script/Code.gs and save. Reload the Google Sheet and run SSV Admin › Set up / repair sheets. It applies the sheet styling and fills empty sections with sample content to replace later.
    6. Run SSV Admin › Set Cloudinary keys once and allow access when Google asks. This fixes the media library error.
    7. Deploy › Manage deployments › Edit › Version: New version › Deploy.
